# Rapporter une preuve

- Marque le verbe : mesuré (tu as exécuté et lu le résultat) ou déduit (tu as lu du code ou un rapport). Jamais « observé » pour quelque chose qu'on a lu. En écrivant « mesuré », nomme ce qui le falsifierait.
- Chaque mesure porte son contrôle de polarité inverse : un vert sans contrôle ne prouve rien, surtout si le jeu de données rend la valeur uniforme.
- Un critère de persistance se vérifie dans la charge utile ou en base, pas à l'écran.
- Une donnée de dev modifiée pour prouver est remise en l'état et vérifiée point par point, pas déclarée.
